How routes are found

Shortest paths, weighed honestly

Each station-on-a-line is a graph node. Dijkstra's algorithm finds the cheapest path for your preference using estimated minutes, interchange walks and active alerts.

Crowd reports

Fresh for 15 minutes

Signed-in commuters report how busy a platform is. Reports expire quickly, and missing data is shown as unknown - never as "quiet".

Alerts

Verified before shown

Moderators publish alerts. A suspended segment is removed from route planning; a delay adds minutes to the affected connections only.
